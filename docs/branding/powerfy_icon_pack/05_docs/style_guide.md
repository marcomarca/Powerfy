# POWERFY · Guía rápida de estilo del icono

## Sistema visual
- Relación base de los activos: 1:1 (cuadrado).
- Símbolo central: casco mecha simétrico, frontal, con lectura inmediata.
- Lenguaje visual: anime-mecha + UI premium + acabado tecnológico.
- Fondo del símbolo maestro y tray icon: transparente.
- Fondo del app icon y favicon/nav icon: azul marino oscuro con degradado suave.

## Jerarquía visual
1. Visor cian: foco principal.
2. Cresta roja: acento secundario de reconocimiento.
3. Carcasa blanca/gris: volumen, estructura y legibilidad.
4. Líneas azul marino oscuro: separación y definición.

## Reglas de uso
- Mantener proporción cuadrada 1:1.
- No deformar el símbolo.
- No cambiar la posición frontal del casco.
- No añadir texto dentro del icono.
- En tamaños muy pequeños, usar la variante tray o favicon, no el símbolo detallado sin simplificar.

## Área de seguridad recomendada
- Símbolo maestro: dejar entre 8% y 10% de margen externo.
- App icon / favicon: dejar entre 10% y 12% de padding dentro del contenedor.
- Tray icon: dejar entre 12% y 15% de padding para evitar pérdida en tamaños de 16px.

## Versiones incluidas
- Símbolo maestro aislado (PNG transparente).
- App icon de Windows (PNG + ICO).
- Tray icon de Windows (PNG + ICO).
- Browser / favicon / nav icon (PNG + ICO).

## Resoluciones incluidas
- Master symbol: 64, 128, 256, 512, 1024, 1254 px.
- App icon: 16, 24, 32, 48, 64, 128, 256, 512, 1024, 1254 px + ICO.
- Tray icon: 16, 20, 24, 32, 40, 48, 64, 128, 256, 1254 px + ICO.
- Browser/fav icon: 16, 32, 48, 64, 128, 256, 512, 1254 px + favicon.ico.
