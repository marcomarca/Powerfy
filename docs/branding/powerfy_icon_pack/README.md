# POWERFY Icon Pack

Contenido del paquete:

- `01_master_symbol/`: símbolo base aislado en PNG transparente.
- `02_app_icon_windows/`: icono principal de aplicación para Windows en PNG e ICO.
- `03_tray_icon_windows/`: icono para system tray de Windows en PNG e ICO.
- `04_browser_favicon_nav/`: icono para navegador / favicon / navegación en PNG e ICO.
- `05_docs/`: prompts, guía de estilo y paleta de color.
- `06_reference/`: tablero de referencia original usado para la dirección visual.

Uso recomendado:

1. Para el ejecutable de escritorio, usar `02_app_icon_windows/powerfy_app_icon.ico`.
2. Para la bandeja del sistema, usar `03_tray_icon_windows/powerfy_tray_icon_16.png` o `powerfy_tray_icon.ico`.
3. Para web / navegador, usar `04_browser_favicon_nav/favicon.ico` y los PNG 16/32/48 según el caso.
4. Para exportaciones adicionales, partir del símbolo maestro en `01_master_symbol/`.
